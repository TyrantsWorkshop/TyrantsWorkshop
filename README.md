I am a Data Science undergraduate studying in Seoul, driven by a passion for building intelligent systems and automating complex workflows. My work bridges the gap between theoretical machine learning and practical, end-to-end web deployment. Whether I am training neural networks, designing database schemas, or generating interactive visuals, I focus on writing clean, optimized code.
